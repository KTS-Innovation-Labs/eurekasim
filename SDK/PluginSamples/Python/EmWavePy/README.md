# ⭐ Electromagnetic Wave Propagation Python Plugin | EurekaSim

A **EmWavePy plugin** created using the **EurekaSim Addin Wizard**.

This plugin allows users to simulate how EM waves behave over time, visualize propagation patterns, and observe wave interactions using customizable simulation parameters.

## Features

 - **Electromagnetic Wave Rendering**: The plugin generates a dynamic EM wave pattern that updates during simulation. 

> ⚠ **Trigger Warning**:  
> The glow simulation may cause **flashing or rapidly changing light patterns**, especially with low simulation intervals. Use with caution if you are sensitive to flashing effects.
